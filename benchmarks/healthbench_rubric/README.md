# HealthBench Rubric Utilities

Shared preparation utilities for HealthBench-style rubric benchmarks.

This directory is not a standalone benchmark. It contains common row
normalization used by:

- `benchmarks/healthbench`
- `benchmarks/healthbench_professional`

Both prepare scripts emit the same direct Gym row schema for the shared
`resources_servers/healthbench_rubric` verifier.
